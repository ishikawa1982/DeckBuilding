# スパイアの残響(DeckBuilding)

スマホで遊べる**ピクセルアート調**のデッキ構築型ローグライク。Slay the Spire ライクなシングルプレイゲームです。
スマホブラウザ向けの PWA として動作し、ホーム画面に追加すればアプリのように遊べます(オフライン対応)。

グラフィックとサウンドはすべてコードで生成しています(画像・音源ファイルなし):
ドット絵はピクセルマトリクス(文字列配列)→ canvas 描画、背景はプロシージャル描画、
BGM・効果音は Web Audio API で波形を直接合成するチップチューン、
フォントは日本語ドットフォント DotGothic16 をバンドル。

## 遊び方

1. マップで光っているマスをタップして塔を登る
2. 戦闘ではエネルギー(毎ターン3)を使ってカードをプレイ
   - カードをタップして選択 → 敵をタップ(単体攻撃)/ もう一度タップ(それ以外)
3. 勝利するとカード報酬。エリート(💀)を倒すとレリックも入手
4. 焚き火(🔥)で回復かカード強化、イベント(❓)では選択肢を選ぶ
5. 15階のボス「深淵の王」を倒せばクリア

進行はブラウザに自動保存されるので、中断しても「続きから」で再開できます。

## 開発

```bash
npm install
npm run dev      # 開発サーバー(スマホ実機なら --host を付けてLAN経由でアクセス)
npm test         # ユニットテスト(vitest)
npm run build    # 本番ビルド(dist/)
npm run preview  # ビルドの動作確認
```

## 技術構成

- **TypeScript + React + Vite** — UIレイヤー
- **ピクセルアート基盤** (`src/gfx/`)
  - `sprites.ts` — 敵8種・主人公・カードアイコン・レリック等のドット絵定義(2フレームアイドルアニメ付き)
  - `Sprite.tsx` — マトリクスを canvas に描画するコンポーネント(`image-rendering: pixelated`)
  - `backgrounds.ts` / `PixelBg.tsx` — タイトル・マップ・戦闘・部屋のプロシージャル背景
  - 戦闘演出はゲームロジックに触れず、状態の差分からUI層で算出(ダメージポップ・画面シェイク・突進・ヒットフラッシュ・撃破ディゾルブ)
- **サウンド基盤** (`src/audio/`)
  - `engine.ts` — Web Audio API のラッパー(オシレーター/ノイズ合成、ミュート状態を永続化)
  - `sfx.ts` — カードプレイ・被弾・撃破・回復などの効果音
  - `music.ts` — タイトル/マップ/戦闘/勝利/敗北のチップチューンBGM(クロスフェード切り替え)
  - 右上の♪ボタンでミュートのON/OFFを切り替え可能
- **純粋TSのゲームコア** (`src/game/`) — UIから独立しておりテスト可能
  - `combat.ts` — 戦闘エンジン(エネルギー、ブロック、筋力/脆弱/弱体/毒などの状態異常)
  - `cards.ts` — カード定義(20種+強化版)
  - `enemies.ts` — 敵AI(8種: 通常5・エリート2・ボス1)
  - `map.ts` — 3レーン×15階の分岐マップ生成
  - `run.ts` — ラン進行とセーブ/ロード
  - `rng.ts` — シード付き乱数(mulberry32)
- **PWA** — `manifest.webmanifest` + サービスワーカーでホーム画面追加・オフラインプレイに対応
